# October2026 — GitHub正本参照

October2026の作業を始めるたびに、必ずGitHubの最新 `main` から次の正本を開いて確認する。

- 共通ルール・公式3役・作業環境： https://github.com/lt068028/october2026/blob/main/AGENTS.md
- 個別指示書・作業手順・GitHub運用： https://github.com/lt068028/october2026/blob/main/docs/RELAY_WORKFLOW.md

作業内容に応じて、これらの正本から参照されている関連仕様書・テスト説明も確認する。Skillや過去の会話に記載された古い内容を、現行ルールとして使用しない。

ユーザーがタスクごとに指定した役割（相談役・分析役・実装担当）に従う。役割をGeminiや特定モデルに固定しない。役割が明確でない場合は、必要な役割を確認する。分析調査は読み取り専用とし、実装はユーザーが承認した範囲に限定する。

GitHubの最新文書を実際に取得・確認できない場合は、その事実を明示し、未確認の規則を最新であるかのように扱わない。ローカル環境の利用、ファイル変更、Commit・Push等は、GitHubの現行規則とユーザーの明示的な許可に従う。

**このSkillにはプロジェクト規則の詳細を複製しない。運営規則の唯一の正本は常にGitHubの最新 `main` とする。**
