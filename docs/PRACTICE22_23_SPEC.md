## 2.2 この・その・あの・どの

### ExampleとDrillの順序

- E1→D1→E2→D2→E3→D3。その後に「この人はだれですか — Under review」を残す。各セクションはExampleを先に置き、その直後に対応Drillの見出しを置く。
- E1・E2・E3の枠ラベルはExample1・Example2・Example3。枠内の重複したExample見出しは付けない。A／BのQuestion・Response見出しがあるモデル再生ボタンは単に「🔊きく」。E1の画像内ボタンは話者識別が必要なのでA🔊きく／B🔊きくを維持する。

### E1・D1：肯定文で値段を述べる

- E1は帽子3種。A側キャップ1,000円、B側つば広帽子3,000円、上段中折れ帽4,000円。A／Bそれぞれ3文、計6文。こ・そ領域は帽子から説明文までを含めるよう下寄り、値札は必須範囲としない。あ領域は帽子と右側の説明文を含める。話者で青／緑が入れ替わり、品物・操作・文字は領域より上。
- D1はAの肯定文3問、番号1・2・3。Set 1カバン3種、Set 2時計3種。「このカバンは、にせんえんです。」等。カバンは2,000／5,000／8,000円、時計は6,000／9,000／10,000円。

### E2・D2：いくらですかの会話

- E2は時計の写真とA「この時計はいくらですか」→B「その時計は、ろくせんえんです」の1組。Example2の枠番号を付け、枠内のExample見出しは付けない。
- D2はカバン・時計の2セット、価格はD1と同じ。各セットA質問→B返答の3会話、番号1・2・3。
- 指示表現の交代が練習点。返答には正しいこの／その／あの＋品名＋価格を必須とし、価格だけの短答、誤った指示表現・品名・価格は不可。共通の省略ルールに対する承認済み例外。Y/Nにはしない。

### E3・D3：どの＋名詞で値段から選ぶ

- E3はおにぎりの写真とA「どのおにぎりが、さんびゃくえんですか」→B「そのおにぎりです」の1組。Example3の枠番号のみ、枠内のExample見出しは付けない。
- D3はSet 1おにぎり、Set 2おべんとう。同じ品名を各位置2個ずつ並べた3群。価格は群全体の合計。おにぎり300／600／900円、おべんとう1,000／2,000／3,000円。
- 各セットA質問→B返答の3会話のみ、番号1・2・3。正しい指示表現＋名詞が必須で「そのです」は不可。正しい価格を補う「そのおにぎりが三百円です」「そのおにぎりは三百円です」も許容。
- どのを含む主語の「が」、品名、価格、返答者視点を照合。色による指定・所有物の質問は使わない。名詞と指示表現は単複で形を変えないと短く補足する。
- ど案内は2.1と同じ雲形・赤系・画像右上、小さい丸は短い棚の右端付近。

### 最下部の検討中課題：この人はだれですか

- 削除・非表示にはせず、E3・D3より後に残す。今後の構成を検討する補足として表示。
- 既存の人物写真でA左・B右、メアリーはA側、たけしはB側、ロバートは遠方。Set 1はA質問、Set 2はB質問、各3会話。短答と正しい返答者視点の主題補完を許容する。
- だれのですかの所有格課題は導入しない。

## 2.3 ここ・そこ・あそこ・どこ

### 画像・役割

- assets/practice23-floors.pngは横長の室内3コマ。左が1F銀行でA、中央が2F喫茶店でB、右が3F図書館で人物なし。建物外観や広場は使わない。階・場所名・A／B・物のPNG・説明・操作はHTMLで重ねる。
- 二人は別の階から通話中と説明。A／Bの物理位置は固定する。Aにとって1Fがここ、2Fがそこ、3Fがあそこ。Bにとって2Fがここ、1Fがそこ、3Fがあそこ。漫画として各階の場面を並べたもので、同じ部屋に並んだ二人の中距離のそこは導入しない。
- 品物は各コマの手前の机に配置。物そのものを指すこれ／それ／あれと、物の置かれた場所を示すここ／そこ／あそこを区別する。

### Example 1・Drill 1

- Exampleは「ここは銀行です」等の場所の紹介を、A／B各3文、計6文。音の説明こ／そ／あも話者に連動させる。
- Drill 1 Set 1は各話者が3つの場所を紹介する計6行。
- Set 2は1Fスマホ／2F辞書／3F財布を置き、「スマホはここです」等、物の所在を各話者3文、計6行で述べる。場所名の画像と階を入れ替えない。

### Drill 2：物はどこですか

- 各セット3問×質問・返答で6行。Aが尋ね、Bが自分の視点でここ／そこ／あそこですと返答する。

| セット | 1F | 2F | 3F |
|---|---|---|---|
| 1 | スマホ | 財布 | 辞書 |
| 2 | ノート | 辞書 | 財布 |

- 「スマホはどこですか」→B「そこです」。正しい品名を補った「スマホはそこです」も許容。違う品名や場所は不可。D2の品物は灰色にし、色を手掛かりにしない。

### Drill 3：指定した物の所在

- 2.1 D3同様、同じ物3色のセットを使う。スマホ／辞書／財布の各2問、計6問。英語の色キューで回答対象を指定し、色名は発話しない。
- 質問「あなたのスマホはどこですか」、返答「そこです」等。問題1はA質問／B返答、問題2はB質問／A返答。「スマホはそこです」「私のスマホはそこです」等の正しい全文も許容する。返答者の視点と対象の階に一致させる。
- 「ど：Asking about the unknown」は図の右上側の独立ガイドとして表示し、写真の階・場所名を隠さない。
