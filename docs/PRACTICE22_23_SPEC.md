## 共通仕様

- 2.2はこの／その／あの＋名詞・どの＋名詞、2.3はここ／そこ／あそこ・どこ。2.1の設定、130％標準表示、本文の滑らかな拡張、語彙Hover／Display／OFF、文法の金色強調、行ごとのきく・とる・停止・認識結果・判定・録音後リレーを継承する。Textボタンは設けない。
- 初期表示Hiragana。With漢字はL1・L2の参考漢字を使用し、かばんはカバン。登場人物のたけしには未習漢字を当てず、武は認識結果の比較時だけ読みへ変換する。固有名はメアリー／たけし／ロバート。
- 音声・認識・録音のライフサイクルは2.1から引き継いだpractice2-next.jsを、新しい2ページだけで共用。既存2.1の録音実装は再構成しない。共通DrillAudio／DrillAnswer／tooltip-layoutを継続使用し、2.1の品物データ・画像素材も再利用する。
- 写真の人物・物・背景は固定し、A／Bのきく・とる・フォーカスで話者表示を切り替える。Who is speaking?は2.2 Exampleでは画像内の独立した最前面、その他は写真の外側に表示する。2.2 ExampleではA／BのPlaying中に背景の濃淡を1.2秒周期で継続し終了・中断時に解除。その他のExampleは1.2秒×3回。reduced-motionでは静的な一時強調。
- Exampleの写真は広幅75％、Drillの写真は60％。900px以下では100％。2.2 Exampleの文はAの3文／Bの3文の2群（600px以下で縦並び）。2.2 Exampleのきくボタンは各帽子に対応した画像内の空き領域にA／B縦並びで配置。Whoは2.1同様に画像左上2％。こはAの肩の右、そはBの肩の左、あは上段帽子の右。その他のページのモデル文3群は900px以下で縦並び、再生ボタンは写真下の3列。
- Set切り替えはそのセクションの画像・モデル・判定を切り替え、スクロール位置とフォーカスを保つ。準備／録音中は禁止。録音・認識・判定はページ内のセット／話者／行ごとに保持し、戻れば復元。再読込を越えた保存は追加しない。
- 会話応答は短い自然な返答をモデルにし、正しい全文・部分補完も登録した範囲で許容する。明示した指示語・人名・品名・所有者・場所は一致が必要。無関係な文を削って正解にはしない。単独文作成の必須要素は減らさない。

## 2.2 この・その・あの・どの

### Example 1・Drill 1：物＋値段

- 基本形は「このスマホは、さんまんえんです。」等。この／その／あのの直後に名詞が必要なことを見出しで示す。所有者を尋ねるだれのですかは導入しない。
- 値段の文で進める案を提示し、選択の返答がないため、ユーザーへの進捗報告で値段を前提とする初期実装と明示した。値段以外を希望された場合はこの部分を調整する。
- 品物用の写真はassets/practice22-shelves.png。Aは左、Bは右に立って棚の商品を見る。左右に各人物の手が届く近い陳列棚、中央奥に両者から離れた棚を置く。棚の写真と商品PNG・値札・A／B・説明を分離し、D1・D3で同じ背景を使用する（Exampleは下記の帽子画像へ更新）。人物用のD2と2.3の画像は変更しない。
- Exampleは採用画像③を基にしたassets/practice22-hats.png（2:1）。後ろ姿の二人を左右へ離し、下段左のキャップ1,000円、下段右のつば広帽子3,000円、上段中央の中折れ帽4,000円を示す。三つとも名詞は帽子。写真に帽子を含め、語彙Hover・値札はHTMLで重ねる。指定の英文説明段落は削除し、見出しのみ残す。Drillの品物・画像は今回維持。A／Bそれぞれ3文、計6文。画像の価格は数字、本文はScript Modeに応じた読み／漢字。話者が替わるとこの／そのを入れ替え、奥の棚はあののままとする。
- Drill 1は各話者3文を1行ずつ録音。Aはこの→その→あの、Bも自分から見たこの→その→あのの順。

| セット | A側 | B側 | 遠方 |
|---|---|---|---|
| 1 | スマホ・3万円 | 財布・2千円 | 辞書・3千円 |
| 2 | ノート・3百円 | 辞書・3千円 | 財布・2千円 |

### Drill 2：この人はだれですか

- 別の人物画像assets/practice22-people.pngを使う。Aは左手前、Bは右手前。青い服のメアリーはA側、緑の服のたけしはB側、赤い服のロバートは遠方。名前はHTMLで示す。
- 「どれ = which one? · だれ = who?」を短く併記し、物を選ぶ質問と人物の名前を尋ねる質問のつながり・違いを示す。だれをど系列の同一形式とは説明しない。
- 例：「この人はだれですか」→「メアリーさんです」。短いExample会話を再生できるようにし、その後3組の質問・返答を個別に録音。Set 1はA質問／B返答、Set 2はB質問／A返答。人物の位置は変えない。
- 返答で「その人はメアリーさんです」等の全文も許容。明示するこの／その／あのは答える側の視点で一致させる。名前だけの正しい述語文も許容し、さんの有無を許容する。違う人物名・指示語は不可。

### Drill 3：どの＋名詞

- 2.1 D3のスマホ／辞書／財布、3色、A側／B側／遠方、各セット2問で計6問を踏襲。問題1はA質問／B返答、問題2はB質問／A返答。
- 質問モデル「あなたのは、どのスマホですか」。主語を補った「あなたのスマホは、どのスマホですか」も許容する。
- 色の英語キューで対象を指定し、「そのスマホです」等、指示語＋名詞で返答。色名は発話させない。「私のスマホはそのスマホです」「私のはそのスマホです」「そのスマホは私のです」等も許容。名詞のない「そのです」、別の指示語・品名は不可。

## 2.3 ここ・そこ・あそこ・どこ

### 画像・役割

- assets/practice23-floors.pngは横長の室内3コマ。左が1F銀行でA、中央が2F喫茶店でB、右が3F図書館で人物なし。建物外観や広場は使わない。階・場所名・A／B・物のPNG・説明・操作はHTMLで重ねる。
- 二人は別の階から通話中と説明。A／Bの物理位置は固定する。Aにとって1Fがここ、2Fがそこ、3Fがあそこ。Bにとって2Fがここ、1Fがそこ、3Fがあそこ。漫画として各階の場面を並べたもので、同じ部屋に並んだ二人の中距離のそこは導入しない。
- 品物は各コマの手前の机に配置。物そのものを指すこれ／それ／あれと、物の置かれた場所を示すここ／そこ／あそこを区別する。

### Example 1・Drill 1

- Exampleは「ここは銀行です」等の場所の紹介を、A／B各3文、計6文。音の説明こ／そ／あも話者に連動させる。
- Drill 1 Set 1は各話者が3つの場所を紹介する計6行。
- Set 2は1Fスマホ／2F辞書／3F財布を置き、「スマホはここです」等、物の所在を各話者3文、計6行で述べる。場所名の画像と階を入れ替えない。

### Drill 2：物はどこですか

- 各セット3問×質問・返答で6行。Aが尋ね、Bが自分の視点でここ／そこ／あそこですと返答する。

| セット | 1F | 2F | 3F |
|---|---|---|---|
| 1 | スマホ | 財布 | 辞書 |
| 2 | ノート | 辞書 | 財布 |

- 「スマホはどこですか」→B「そこです」。正しい品名を補った「スマホはそこです」も許容。違う品名や場所は不可。D2の品物は灰色にし、色を手掛かりにしない。

### Drill 3：指定した物の所在

- 2.1 D3同様、同じ物3色のセットを使う。スマホ／辞書／財布の各2問、計6問。英語の色キューで回答対象を指定し、色名は発話しない。
- 質問「あなたのスマホはどこですか」、返答「そこです」等。問題1はA質問／B返答、問題2はB質問／A返答。「スマホはそこです」「私のスマホはそこです」等の正しい全文も許容する。返答者の視点と対象の階に一致させる。
- 「ど：Asking about the unknown」は図の右上側の独立ガイドとして表示し、写真の階・場所名を隠さない。

## 検証と限界
