## 2.2 この・その・あの・どの

### Example 1・Drill 1：物＋値段

- 基本形は「このスマホは、さんまんえんです。」等。この／その／あのの直後に名詞が必要なことを見出しで示す。所有者を尋ねるだれのですかは導入しない。
- 値段の文で進める案を提示し、選択の返答がないため、ユーザーへの進捗報告で値段を前提とする初期実装と明示した。値段以外を希望された場合はこの部分を調整する。
- 品物用の写真はassets/practice22-shelves.png。Aは左、Bは右に立って棚の商品を見る。左右に各人物の手が届く近い陳列棚、中央奥に両者から離れた棚を置く。棚の写真と商品PNG・値札・A／B・説明を分離し、D1・D3で同じ背景を使用する（Exampleは下記の帽子画像へ更新）。人物用のD2と2.3の画像は変更しない。
- Exampleは採用画像③を基にしたassets/practice22-hats.png（2:1）。後ろ姿の二人を左右へ離し、下段左のキャップ1,000円、下段右のつば広帽子3,000円、上段中央の中折れ帽4,000円を示す。三つとも名詞は帽子。写真に帽子を含め、語彙Hover・値札はHTMLで重ねる。指定の英文説明段落は削除し、見出しのみ残す。こ／そ／あの色領域を追加。色は話者A/Bに連動し、帽子・文字・操作は領域より上。A／Bそれぞれ3文、計6文。画像の価格は数字、本文はScript Modeに応じた読み／漢字。話者が替わるとこの／そのを入れ替え、奥の棚はあののままとする。
- Drill 1は値段の会話。選択セットの品物・価格で短い会話例を添え、各セットはA質問→B返答の3組のみ。質問「このカバンはいくらですか」→返答「そのカバンは、にせんえんです」。指示表現の交代が練習点のため、会話の既知部分省略という共通仕様の承認済み例外とする。価格だけの短答は不可、誤った指示表現・品名・価格も不可。Y/Nにはしない。
- Set 1は形の違うカバン3点（リュック・手提げ・ショルダー）、Set 2は時計3点（置時計2種・腕時計）。カバンはA側2,000円・B側5,000円・上段8,000円、時計は6,000円・9,000円・10,000円。Exampleと同じ後ろ姿・分離棚2:1構図を使用する。

### Drill 2：この人はだれですか

- 別の人物画像assets/practice22-people.pngを使う。Aは左手前、Bは右手前。青い服のメアリーはA側、緑の服のたけしはB側、赤い服のロバートは遠方。名前はHTMLで示す。
- 「どれ = which one? · だれ = who?」を短く併記し、物を選ぶ質問と人物の名前を尋ねる質問のつながり・違いを示す。だれをど系列の同一形式とは説明しない。
- 例：「この人はだれですか」→「メアリーさんです」。短いExample会話を再生できるようにし、その後3組の質問・返答を個別に録音。Set 1はA質問／B返答、Set 2はB質問／A返答。人物の位置は変えない。
- 返答で「その人はメアリーさんです」等の全文も許容。明示するこの／その／あのは答える側の視点で一致させる。名前だけの正しい述語文も許容し、さんの有無を許容する。違う人物名・指示語は不可。

### Drill 3：どの＋名詞で値段から選ぶ

- Set 1おにぎり、Set 2おべんとう。同じ品名のものを各位置に2個ずつ並べた3群。価格は群全体の合計と英文で明記。おにぎりはA側300円・B側600円・上段900円、おべんとうは1,000円・2,000円・3,000円。
- 各セットに短い会話例。A3問・B3問、各問に質問・返答の2行。「どのおにぎりが、さんびゃくえんですか」→返答者視点の「そのおにぎりです」。正しい指示語＋名詞は必須で、「そのです」は不可。正しい「そのおにぎりが三百円です」「そのおにぎりは三百円です」も許容。
- どのを含む主語には「が」を使用し、価格・品名・がの一致を確認する。色による指定・所有物の質問はこのページのD3では使用しない。2.3のD3は従来仕様を維持。
- 単数／複数で名詞とこの／その／あのの形を変えないことを短く補足。数詞・助数詞の発話は課題に追加しない。どの案内は2.1と同じ雲形・赤系・どの文字と説明の縦配置、画像右上へ。小さい丸は短い棚の右端付近に置く。語彙ヒント、話者表示、録音・判定・リレー、セット別結果保持は継承。


## 2.3 ここ・そこ・あそこ・どこ

### 画像・役割

- assets/practice23-floors.pngは横長の室内3コマ。左が1F銀行でA、中央が2F喫茶店でB、右が3F図書館で人物なし。建物外観や広場は使わない。階・場所名・A／B・物のPNG・説明・操作はHTMLで重ねる。
- 二人は別の階から通話中と説明。A／Bの物理位置は固定する。Aにとって1Fがここ、2Fがそこ、3Fがあそこ。Bにとって2Fがここ、1Fがそこ、3Fがあそこ。漫画として各階の場面を並べたもので、同じ部屋に並んだ二人の中距離のそこは導入しない。
- 品物は各コマの手前の机に配置。物そのものを指すこれ／それ／あれと、物の置かれた場所を示すここ／そこ／あそこを区別する。

### Example 1・Drill 1

- Exampleは「ここは銀行です」等の場所の紹介を、A／B各3文、計6文。音の説明こ／そ／あも話者に連動させる。
- Drill 1 Set 1は各話者が3つの場所を紹介する計6行。
- Set 2は1Fスマホ／2F辞書／3F財布を置き、「スマホはここです」等、物の所在を各話者3文、計6行で述べる。場所名の画像と階を入れ替えない。

### Drill 2：物はどこですか

- 各セット3問×質問・返答で6行。Aが尋ね、Bが自分の視点でここ／そこ／あそこですと返答する。

| セット | 1F | 2F | 3F |
|---|---|---|---|
| 1 | スマホ | 財布 | 辞書 |
| 2 | ノート | 辞書 | 財布 |

- 「スマホはどこですか」→B「そこです」。正しい品名を補った「スマホはそこです」も許容。違う品名や場所は不可。D2の品物は灰色にし、色を手掛かりにしない。

### Drill 3：指定した物の所在

- 2.1 D3同様、同じ物3色のセットを使う。スマホ／辞書／財布の各2問、計6問。英語の色キューで回答対象を指定し、色名は発話しない。
- 質問「あなたのスマホはどこですか」、返答「そこです」等。問題1はA質問／B返答、問題2はB質問／A返答。「スマホはそこです」「私のスマホはそこです」等の正しい全文も許容する。返答者の視点と対象の階に一致させる。
- 「ど：Asking about the unknown」は図の右上側の独立ガイドとして表示し、写真の階・場所名を隠さない。

## 学習目的と共通仕様が衝突する場合
- 指示表現の交代などの学習目標を、会話の省略等の共通仕様が弱める場合は、機械的に共通仕様を適用しない。変更前に「練習点・衝突する仕様・例外案・正答の許容範囲」を説明してユーザーへ確認する。承認済みの個別例外は再確認しない。
- 今回の承認済み例外は2.2 D1の指示表現＋名詞＋価格の完全返答。2.1や2.3等の既存の短答ルールへ自動拡張しない。
