## 1. Practice 2.2・2.3の共通原則

- Practice 2.2は「この／その／あの＋名詞」「どの＋名詞」「だれ」、Practice 2.3は「ここ／そこ／あそこ」「どこ」を扱う。
- 既定の表示はHiraganaとする。With漢字ではL1・L2語彙欄の参考漢字を使用し、かばんは「カバン」と表記する。たけしの名前に未習漢字を当てず、「武」は認識結果の比較時だけ読みへ変換する。固有名はメアリー／たけし／ロバートとする。
- 共通の設定、標準表示、語彙Hover／Display／OFF、文法強調、行ごとの再生・録音・停止・認識結果・判定・録音後リレーを継承する。独立したTextボタンは設けない。
- 会話応答は自然な短答を基本とし、正しい全文・部分補完も各設問で登録した範囲に限って許容する。明示された指示語・人名・品名・所有者・場所が異なる回答や、無関係な文を削って正解にする方式は採らない。単独文作成の必須要素は省略しない。
- 共通原則と学習目標が衝突する場合は、機械的に共通原則を適用せず、学習上の目的と必要な回答許容を確認する。承認済みの個別例外は自動的に他設問・他ページへ拡張しない。
- Set／モード切替では対応する画像・キュー・モデル・判定対象を同期させる。録音・認識・判定結果はページ内で切替前の状態へ戻ったときに復元し、ページ再読込を越える永続保存は追加しない。マイク準備中／録音中は切替を無効化する。

## 2. Practice 2.2 — この・その・あの・どの

### 2.1 学習課題の順序

順序は E1 → D1 → E2 → D2 → E3 → D3 → D4 → D5 とする。D1〜D3は対応するExampleの直後に配置する。D4は「だれ」の導入を説明内で行い、独立Exampleは設けない。D5は「どのかさ」と「どれ」を比較する独立Drillとする。

### 2.2 E1・D1：肯定文で値段を述べる

- D1の説明は「💡Name the item and say its price.」とする。
- E1は帽子3種を用いる。A側のキャップは1,000円、B側のつば広帽子は3,000円、遠方の中折れ帽は4,000円。A／Bそれぞれ3文、計6文とする。
- E1では、話者に応じて「こ／そ」の近接関係が入れ替わる。「あ」は両者から遠い位置を示す。品物・操作・説明文は位置関係の理解を妨げないように配置する。
- D1はBの「その」→Aの「この」→Bの「あの」の順で、肯定文を3問出す。Set 1はカバン、Set 2は時計を使う。最初の2問は同じA側の品物を異なる話者視点から指す。
- Set 1のカバンは2,000円／5,000円／8,000円、Set 2の時計は6,000円／9,000円／10,000円とする。Set切替時も対応するモデル・価格・画像・判定対象を一致させる。

### 2.3 E2・D2：いくらですか

- D2の説明は「💡A: Ask the price and answer.」とする。Aが質問し、Bが返答する。
- E2は時計の写真を用い、A「この時計はいくらですか」→B「その時計は、ろくせんえんです」の1組とする。
- D2はカバン／時計の2セットとし、各セット3組の質問・返答を個別に再生・録音・判定する。価格はD1と同じ。
- **承認済みの学習上の例外**：返答には正しい「この／その／あの＋品名＋価格」を含める。価格だけの短答は許容しない。指示表現の交代そのものが学習目標であるため、共通の短答許容を機械的に適用しない。誤った指示表現・品名・価格は正解としない。Y/N形式にはしない。

### 2.4 E3・D3：どの＋名詞で値段から選ぶ

- E3は、りんご300円・バナナ100円・みかん200円の果物写真を用いる。モデルはA「どのくだものが、さんびゃくえんですか」→B「そのくだものです」。
- D3はSet 1をおにぎり、Set 2をおべんとうとする。同じ品名を各位置に2個ずつ並べた3群を用い、価格は群全体の合計とする。おにぎりは300円／600円／900円、おべんとうは1,000円／2,000円／3,000円。
- 各セットはAの質問→Bの返答を3組とする。返答には正しい指示表現＋名詞が必須で、「そのです」は不可。正しい価格を補った「そのおにぎりが三百円です」「そのおにぎりは三百円です」等は許容する。
- 質問では「どの」を含む主語の「が」を含め、品名と価格を照合する。返答では指示表現・名詞・返答者視点・価格を照合する。色による正答指定や所有物の質問は使わない。名詞と指示表現は単複で形を変えない。Drill説明に独立した補足説明を追加しない。
- どの吹き出しの文字が価格と重なる、または写真内に収まらない場合に限り、同じ吹き出しを写真直下へ移す。収まる場合は写真内に置く。文字サイズ・色・写真と品物の関係を変えず、価格の視認性を優先する。写真下の操作群は共通UIの内容幅判断に従う。

### 2.5 D4：だれ・クラスメートの人物課題

D4はD3の「どの＋名詞」と分離した人物課題とし、Exampleは設けない。Set 1は「だれ」、Set 2はクラスメートとの関係と「どの人」を扱う。

- タイトルは`Drill 4: どの＋Noun / だれ for people`とする。Set 1／Set 2共通の説明は`💡Use だれ to ask who a person is.`とし、説明文中の「だれ」は新登場の学習対象を示す局所的な強調色（`grammar-highlight`）を維持する。他のDrillへこの強調を一律適用しない。
- D4は「だれ」を使って人物について尋ねる表現と、クラスメート／どの人を扱う。ここでは課題が使用する語・形式を指定しているため、「だれ」や「どの人」を日本語キュー本文に含めてよい。これは学習者に疑問詞を自由選択させる課題ではない。キューの考え方は [PROJECT_SPEC.md](PROJECT_SPEC.md) §3.1に従う。
- Q側の語彙Tooltipは「この人／その人／あの人／だれ／どの人」には付けない。Set 2の「Xさん／Yさんのクラスメート」など、文生成に必要な人物関係を示す語彙Tooltipは維持する。A側の後続語彙・名前のTooltip、および写真・画像上の人物名`imageHint()`は維持する。Tooltipの削除は日本語キュー本文の削除を意味しない。
- 写真の人物はメアリー、たけし、ロバート。メアリーとたけしはそれぞれA／Bの会話に登場し、ロバートは紹介される第三者として扱う。人物名は必要なHoverで表示し、人物ラベルのない人を発話者にしない。
- Set 1の3会話は次のとおり。質問者／返答者の順はA→B、B→A、A→B。
  1. A「その人はだれですか」→B「この人はたけしさんです」
  2. B「その人はだれですか」→A「この人はメアリーさんです」
  3. A「あの人はだれですか」→B「あの人はロバートさんです」
- Set 1では、正しい人名だけの短答と、返答者視点の正しい指示表現＋人＋名前の補完を許容する。誤った人名・指示表現は不可。
- Set 2の3会話は、1・2問目でクラスメートかを問い、否定して正しい関係を返し、3問目でクラスメートを選ぶ。
  1. AがBさんのクラスメートかを尋ね、Bは「いいえ、この人は私の弟です」と返す。
  2. BがAさんのクラスメートかを尋ね、Aは「いいえ、この人は私の友達です」と返す。
  3. A「Yさんのクラスメートは、どのひとですか」→B「あのひとです」。
- Set 2の3問目は、正しい「私のクラスメートはあの人です」等の補完を許容する。誤った指示表現、人間関係、肯否は不可。1・2問目のCasualは「ううん」、Formal／Informalは「いいえ」を用いる。停止ボタン横の補助文は1・2問目だけに表示し、3問目には付けない。
- Set 1／2とも会話行ごとの録音・認識・判定状態を分離して保持する。人物紹介の対象は発話者として強調しない。

### 2.6 D5：どの＋Noun／どれによる物の特定

- 同じ3本の傘と同じ3組の会話を用い、Set 1「Adjectives」とSet 2「Pronouns」で比較する。Exampleは追加しない。各セットは3組のQuestion／Response、計6行とする。
- 話者順は両形式共通で、1問目B→A、2問目A→B、3問目B→A。
- 傘の所有と位置は、A所有の黄色い傘が遠方、B所有の青い傘がB側、先生所有の赤い傘がA側とする。所有者と近接領域を混同しない。画像上に所有者名の常時ガイドを出さず、話者ラベルと必要な傘の語彙Hoverを用いる。
- Adjectivesでは「どのかさ」と「この／その／あのかさ」を使用する。Pronounsでは質問を「どれ」、返答を「これ／それ／あれ」へ置き換える。会話の対応は次のとおり。

| 問 | 質問者のキュー | 返答者のキュー | Adjectives | Pronouns |
| --- | --- | --- | --- | --- |
| 1 | Aさんのかさ／どのかさ | あのかさ | あのかさ | あれ |
| 2 | Bさんのかさ／どのかさ | このかさ | このかさ | これ |
| 3 | せんせいのかさ／どのかさ | このかさ | このかさ | これ |

- 対応する所有名詞句を補った全文も許容する。ただし比較対象が学習目標のため、Adjectivesの返答に代名詞だけを用いること、Pronounsの返答に「その傘」等の名詞句を用いること、「そのです」や誤った指示表現は不可。
- タイトルは`Drill 5: どの＋Noun / どれ for objects`、説明は`💡Identify a specific item by asking with どの＋Noun or どれ.`とする。
- Q側の「どのかさ／どの傘／どれ」には語彙Tooltipを付けない。一方、質問キューの所有者＋傘を示す語彙Tooltipと、写真上の所有者を示す`imageHint()`は維持する。A側の返答Cueは既存の色記号（🟡／🔵／🔴）を維持する。Tooltipを削除しても主キューの表現は削除しない。
- 傘の色は回答に使用しない。Set切替・再描画後も録音・認識・判定状態を保持し、マイク準備／録音中は切替を無効化する。

### 2.7 English Cues

- English Cuesの適用対象はD1〜D5の問題キューとする。切替・スクロール・状態保持等の共通動作は [PROJECT_SPEC.md](PROJECT_SPEC.md) §7.1に従う。
- English Cuesでは、指示表現「あの」を`that`、人物表現「あの人」を`that person`とする。`over there`を付け足さず、対象語に合った短い表現を用いる。


## 3. Practice 2.3 — ここ・そこ・あそこ・どこ

### 3.1 ページ構成と登場人物

順序はEx1 → D1（Country／Cities／Time）→ D2（Where?）→ D3（Ask and answer）→ D4（English Cues）とする。Exampleで質問・返答を示すため、重複するExampleは追加しない。

- 図のAは日本、Bはイギリス、Cはアメリカにいる。Cは第三者として所在地・場所の説明対象にする。Cにモデル音声、質問者、返答者、録音役を割り当てない。
- Ex1の通話状況を示す案内は、AとBがCについて話している場面情報として維持する。これはWho案内やQ/A役割表示とは異なる。
- こ／そ／あは話者の位置関係に応じて扱う。人物・場所・背景の対応は固定し、話者視点の切替によって物理的配置を変更しない。

### 3.2 Ex1：導入と会話

- Ex1は日本のA、イギリスのB、アメリカのCを示す画像と、導入・5つのモデル音声から構成する。
- 導入文「私は日本です」は独立行とし、音声を付けない。続く5つの音声行は、話者・キュー・モデルの順で示す。
  1. A「ここ／あさ」：ここは、あさです。
  2. A「Bさん／どこ」：Bさんは、どこですか。
  3. B「ここ／よる」：ここは、よるです。
  4. A「Cさん／どこ」：Cさんは、どこですか。
  5. B「あそこ／ゆうがた」：あそこは、ゆうがたです。
- 導入文「私は日本です」、質問後に示すBの所在地「私はイギリスです」、Cの所在地「Cさんはアメリカです」は、それぞれ音声行とは分けた表示文として残す。これらに独立した質問・音声は追加しない。「Bさんはイギリスですか」という質問も設けない。
- 「ど」の概念表示はEx1だけに置き、場所を示す「こ／そ／あ」とは異なる疑問概念として扱う。Drillには追加しない。

### 3.3 D1：From A’s point of view

- 説明は「💡You are A. Make each sentence using ここ, そこ, or あそこ.」とする。
- Country／Cities／Timeの3モードを設け、各モード3問、すべてAの視点で文を作る。
  - Country：日本／フランス／アメリカを、ここ／そこ／あそこで説明する。
  - Cities：大阪／パリ／ロサンゼルスを、ここ／そこ／あそこで説明する。
  - Time：朝六時／夜十時／午後一時を、ここ／そこ／あそこで説明する。
- Country／Cities／Timeの選択に合わせて、画像ヒント・問題キュー・モデル・判定対象を一緒に切り替える。録音・判定キーはモード別に保持し、別モードの結果を流用しない。
- Timeでは各画像に6:00／22:00／13:00を表示する。Citiesでは都市名を表示する。Countryでは時刻・都市名を表示しない。時刻・都市名のヒントは選択モードと同期する。

- 各問のA表記を繰り返さず、対応する画像内のAと話者強調で示す。

### 3.4 D2：Where? — 人物と持ち物の所在

- 銀行にいるA、喫茶店にいるB、図書館にいるCの画像を使用し、People／Item1／Item2を切り替える。
- Peopleは3会話とする。
  1. A「Bさんはどこですか」→B「ここは喫茶店です」。
  2. B「Aさんはどこですか」→A「ここは銀行です」。
  3. B「Cさんはどこですか」→A「Cさんは図書館です」。
- Peopleの返答キューは、順に「ここ／喫茶店」「ここ／銀行」「Cさん／図書館」とする。既知の主語を省いた短答や、正しい場所を述べる補完文を許容する。喫茶店については「カフェです」と正しい補完文も許容する。
- Item1はカバン・本・ノート・ペンの4会話とする。対象位置はカバン＝A、本＝C、ノート＝C、ペン＝B。1〜3問目はB質問→A返答、4問目はA質問→B返答。
  - モデルは「カバンはここです」「本はあそこです」「ノートもあそこです」「ペンはここです」。
  - ノートは直前の本と同じC側なので「も」をモデルにする。「ノートはあそこです」も許容する。
  - 正しい場所だけの短答、または品名を補った正しい文を許容する。誤った指示語・品名・場所は不可。
- Item2はItem1と同じ4品・配置・話者構成を使い、所在地を否定して正しい位置を返す。
  1. B「カバン／あそこ」→A「いいえ、あそこじゃないです。ここです」。
  2. B「本／ここ」→A「いいえ、そこじゃないです。あそこです」。
  3. B「ノート／そこ」→A「いいえ、ここじゃないです。あそこです」。
  4. A「ペン／あそこ」→B「いいえ、あそこじゃないです。ここです」。
- Item2は正しい場所の短答、品名付き肯定、いいえ＋短答、否定＋短答を許容する。「いいえ」だけ、否定だけ、誤った指示語・品名・場所は正解としない。否定表現は話者視点に合わせて変換し、停止ボタン横の補助文はFormal／Informalで「いいえ…」、Casualで「ううん…」とする。
- Item1／Item2では対象品物を識別する表示と、返答で正しい場所を示す表示を区別する。質問で答えの場所を先に示さない。対象品物の強調は、質問で探す物の識別と、返答時に正答を示す目的を混同しない。
- Cは所在地・持ち物の説明対象であり、発話・録音役にしない。録音・判定キーはモード／セット／行で分離し、切替・設定変更後もページ内の結果を保持する。

### 3.5 D3：Ask and answer

- D1と同じ画像・国／都市／時刻データを共有し、Country／Cities／Time／Dayを独立して切り替える。各モード3会話、各会話はQuestion／Responseの2行とする。
- Country：
  1. A「そこはどこですか」→B「ここはフランスです」。
  2. B「そこはどこですか」→A「ここは日本です」。
  3. B「Cさんはどこですか」→A「Cさんはアメリカです」。
- Cities：
  1. A「そこはフランスのどこですか」→B「ここはパリです」。
  2. B「そこは日本のどこですか」→A「ここは大阪です」。
  3. A「Cさんはアメリカのどこですか」→B「あそこはロサンゼルスです」。
  - 返答キューは順に「ここ／パリ」「ここ／おおさか（大阪）」「あそこ／ロサンゼルス」とし、国名を重複表示しない。
- Time：
  1. A「そこは何時ですか」→B「ここは夜十時です」。
  2. B「そこは何時ですか」→A「ここは朝六時です」。
  3. A「あそこは何時ですか」→B「あそこは午後一時です」。
  - 対応する時刻は6:00／22:00／13:00とする。
- Day：
  1. A「そこは何曜日ですか」→B「ここは土曜日です」。
  2. B「そこは何曜日ですか」→A「ここは日曜日です」。
  3. A「あそこは何曜日ですか」→B「あそこも土曜日です」。「あそこは土曜日です」も許容する。
  - 同時刻設定はA＝日曜06:00、B＝土曜22:00、C＝土曜13:00。画像表示はSun.／Sat.／Sat.とし、Script Modeによって略語を変えない。
  - 返答キューは「ここ／どようび」「ここ／にちようび」「あそこ／どようび」とする。With漢字では土曜日／日曜日を表示する。
  - 正しい曜日だけの短答も許容する。別の曜日・誤った指示語は不可。
  - 土日と「何曜日」は、このPractice 2で先行導入する承認済みの例外とする。これを理由に「します」等の他のL3文型・語彙を追加しない。D1にはDayモードを追加しない。
- Citiesは都市名だけの短答、「フランスのパリです」等の国名を含む補完、既知の主語を省略した自然な短答も許容する。Timeは同じ時刻を表す午前／午後・24時間表記を許容し、文脈から午前午後が明らかな裸の時刻も許容する。誤った午前／午後、国・都市・曜日、明示された指示語は許容しない。
- Cは第三者であり、質問・返答・録音役にしない。D3の録音・判定はモード別に保持し、D1／D2と混同しない。

### English Cues切替パネル

- English Cuesの適用対象はD1〜D3の問題キューとする。D3 Dayの返答キューは`Saturday`／`Sunday`とする。
- D1（Country／Cities／Time）は国名・都市名・時刻等の問題情報を切り替え、場所を表す「あそこ」等の英語Cueは追加しない。D2／D3の所在・場所Cueに「あそこ」が現れる場合は`there`とし、`over there`にはしない。
- 切替操作・スクロール・録音状態の保持等は [PROJECT_SPEC.md](PROJECT_SPEC.md) §7.1に従う。

## 4. 話者・対象物の表示条件

### 4.1 視点表示と実際の話者強調を区別する

- 教材内でどちらの人物視点を示すかという表示切替と、音声・録音処理中の話者強調は別の状態として扱う。
- Practice 2.2の視点表示は、対応するA／Bのきく・とる操作およびフォーカスに応じて切り替える。
- Practice 2.3の視点表示は、再生または録音開始で切り替え、フォーカスだけでは切り替えない。
- 実際の話者強調は、実際のモデル音声／録音音声の再生、マイク準備、録音に対応する人物だけを対象とする。終了・中断・エラーで解除し、Cや紹介対象を発話者として扱わない。
- 話者強調の外観・アニメーション・reduced-motion時の扱いは [UI_LAYOUT_SPEC.md](UI_LAYOUT_SPEC.md) §7.3を正本とする。旧方式の赤点滅を現行表示として適用しない。Who is speaking?の案内表示はPractice 2.1／2.2では設けない。

### 4.2 対象物の強調

- 人物の話者強調と、設問で対象となる品物・場所の強調を混同しない。
- Practice 2.2の「どの／どれ」で正答を選ぶ課題では、質問・質問へのフォーカス段階で正答対象を先に強調しない。指示表現を使う返答段階で必要な対象だけを示す。対象はE3／D3、D4 Set 2の「どの人」、D5の比較課題に適用する。
- Practice 2.3の所在課題では、質問で探す対象物を識別する表示と、返答で正しい場所を示す表示を区別する。全画像の対象強調を一律に撤去しない。
- 対象表示のページ内適用箇所と条件は、本書のPractice 2.2／2.3各課題の規定に従う。
