# Practice 2.1〜2.3 — 話者強調の適用範囲

> 本書は、Practice 2.1〜2.3において、どの発話・録音行の人物ラベルを話者強調の対象とするかを整理する適用範囲表である。共通の外観・アニメーション・reduced-motion時の表示は [UI_LAYOUT_SPEC.md](UI_LAYOUT_SPEC.md) §7.3を正本とする。ページ内の視点表示や状態切替は [PRACTICE2_SPEC.md](PRACTICE2_SPEC.md) および [PRACTICE22_23_SPEC.md](PRACTICE22_23_SPEC.md) に従う。採用・展開経緯は [UI_ROLLOUT_REVIEW.md](UI_ROLLOUT_REVIEW.md) を参照する。

## 1. 共通適用条件

- 話者強調は実際のモデル音声再生、学習者の録音音声再生、マイク準備、録音中に、その時点で対応する実際の話者A/Bだけに適用する。
- 発話・録音の終了、中断、停止、エラー時には解除する。別の話者の発話・録音へ移行した場合は対象を切り替える。
- 第三者Cや、会話で紹介・説明される人物を発話者として強調しない。
- 操作フォーカスによる教材内の視点表示切替と、実際に発話・録音処理中の話者強調は別の機能とする。フォーカスだけで発話中の強調を開始しない。
- 旧方式の赤点滅は現行表示ではない。現行の人物ラベルの色を維持した白い輪郭による強調を使用する。具体的な表示値はUI_LAYOUT_SPEC §7.3を参照する。

## 3. 関連する別機能との区別

- Q/Aアイコンは質問・回答の役割表示であり、実際の話者強調とは別機能とする。
- 人物ラベルは話者・登場人物を識別する表示であり、実際に発話・録音処理中でない人物を強調しない。
- 対象品物・場所の青い強調は、学習者が対象を識別するための別機能である。質問で正答を先に示さない条件や返答時の表示は、各ページ固有仕様および [UI_ROLLOUT_REVIEW.md](UI_ROLLOUT_REVIEW.md) の対象品物強調ルールに従う。
- 2.2の教材内視点表示はA／Bのきく・とる操作やフォーカスに応じて切り替わる場合があるが、これだけで実際の話者強調を発火させない。2.3では教材内の視点表示も再生または録音開始で切り替え、フォーカスだけでは切り替えない。詳細は各ページ仕様を参照する。
