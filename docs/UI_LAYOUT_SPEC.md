## キュー・矢印・音声列

- キューの列幅は内容基準。Drillでは同一Drill内の最長キュー幅を共有し、Exampleでは同一Example内で共有する。ページ全体のすべてのDrillを1つの列へ揃える仕様ではない。
- JSが測定結果をpxで保持しても、任意の固定幅を設定するのとは区別する。実測・内容幅を使い、狭幅用の割合上限と標準カード幅から導く上限で折り返す。余剰幅をキューへ配分しない。
- 1.2 Example 1／2は、ラベル・キュー・矢印・音声＋本文の共通列。矢印をキュー内へ埋め込まない。短いキューの行で生じる列揃え用の空きは矢印より前へ集め、矢印ときくの間は列間隔とセルpaddingだけにする。
- 狭幅ではラベル／キューを上段へ移し、矢印・きく・本文を同じ下段へ置く。矢印だけを上段へ取り残さない。
- 7.1／7.2／7.3 Example 2は質問・Yes・Noの3音声ボタンを同一の縦列に並べる。Yes／No本文も縦並び。
- 問題カードの結果は右寄せを基本とし、短ければ操作と同じ段、長ければ下段へ折り返す。停止から右端の結果までの空きは、結果領域を確保するためのもの。キューの不要余白とは区別する。

## 区分と強調

- 練習7の比較型Example：区分→キュー→矢印→きく→本文。比較する異なる区分は各行に残す。
- Question／Response型Example：Questionの1行上に共通区分見出し1個。各行に区分を重複させない。Question／Responseの役割表示は維持。
- 比較Drill：きく→区分→とる→停止の順。区分はきくの右隣。単一区分に絞った練習では、既定の問題行に区分を追加しない。
- 文法強調：既定の文法部分を太字＋ゴールド。通常色#ca8a04、ダーク#fbbf24。すべての太字をゴールドにする仕様ではない。

## 整理結果と残る判断事項

1. **練習7の区分幅**：7.1／7.2／7.3へ共通適用。同じ比較Drill・Example内で、最長区分の自然幅を背景幅として共有する。最長区分は引き伸ばさない。短い名称は文字間に加える間隔を最大3.5pxとして均等配置する（Pastも同じ規則）。最長背景幅と通常の左右余白を維持できる範囲で広げ、3.5pxに達したら残りを余白へ回す。文字全体の47px上限は設けない。最長名称は通常字間。残りは左右余白へ配分し、中央へ配置する。単独の区分見出しは自然幅。色・区分位置・操作順は維持する。
2. **Vocabの対象範囲**：キュー側のみへ確定。7.2 Example 1の本文にあったヒント重複を撤去。ほかの文法Exampleにも本文ヒントがないことを確認する。英語キュー練習の既存内容変換は別機能であり今回変更しない。
3. **折り返し境界**：Example・表形式Drillのカード境界は850pxへ統一済み（従来の1.2 Example 800pxを撤去）。ヘッダー/設定/キュー切替パネルの600px、Pitch Labの2列→1列の680pxは別部品の構造切替なので維持する。これらをExampleの段組み境界と混同しない。自動テストでカード内容幅849/850/851pxの前後を確認する。
4. **PC最小幅**：自動検証の基準は画面600px以上。600px未満のPCウィンドウでどこまで配置を保証するかは未決。スマホの音声認識・判定対応保留とは別の事項。

## 説明文の段落・文言（2026-10-26確定方針）

- 短い同目的の説明は一段落。課題と補足、独立した操作手順は分ける。句点ごとの一律改行にはしない。各段落は狭幅で自然に折り返す。
- 課題を動詞で先に示し、タイトル・Exampleと重複する前置きを省く。学生に実際の操作と必要な文型が伝わることを文字数より優先する。
- 1.1の自由入力、1.2の質問/返答、練習7のY/Nは操作手順を分ける。7.1拡張キューは課題/助詞/例外を分ける。7.2 D1は課題とからの規則を分ける。発音Labは模倣とピッチ線比較を分ける。
- Y/NはAsk a Yes/No questionを共通表現とし、Wh質問の指示と混同させない。1.2 D1の両返答練習、7.1の先生に＋聞く/急ぐの例外、からの開始時刻・のの結合、発音のpronunciation/rhythm/timingを残す。
- 変更前は7.2 D1だけが2文ブロックで、他ページの複数文は基本1段落だった。前後の全文・段落数・短縮量は[INSTRUCTION_REVIEW.md](INSTRUCTION_REVIEW.md)に記録する。既定表示＋7.1拡張キューの確認対象で約31%短縮。
- 区分案の意図は短いPastだけの余白増と均等配置であり、長いPresent Stateへも余白を増やす案ではないと確認済み。7.2のみで試験し、他ページへの展開は実機評価後に判断する。
