# STT結果表示の共通ルール

更新：2026-10-30。確定した表示ルールと境界例を記載する。本書は認識結果表示の仕様として旧辞書変換/句読点削除の記述より優先する。認識結果を扱う全11ページに表示専用処理 `stt-display.js` を実装。判定・モデル音声の変換とは分離した。

## 対象とデータの分離

- 認識結果を扱う全11ページへ適用。発音1はSTT文字抽出を行わず対象外。
- STTの原文、表示用テキスト、判定用テキスト、TTSモデル用テキストは分離する。表示のための変換で原文を上書きしない。原文保存時にtrim/NFKC等で文字を変更する処理も改修時の点検対象にする。
- 認識APIは漢字/ひらがな/カタカナ/英字を返し得る。必ず漢字で返すわけではなく、アプリからすべてひらがなにする指定もできない。TTSとSTTは別経路。

Hiragana Onlyの現行ボタン名は変更しない。仕様上は漢字を使わない基本表示とし、課ごとのカタカナ保持と、Tシャツ/Form等の英字例外を明記する。

## 確定した表示規則

| 項目 | 規則・範囲 |
| --- | --- |
| 既存ひらがな | Hiragana OnlyではSTTが最初からひらがなで返した語を保持。なにですかをなんですかへ書き換えない。明示した表示例外だけを別管理。 |
| 漢字の読み | Hiragana Onlyで何ですかはなんですか。何を/何がはなにを/なにが、何のはなんの、何時はなんじ、何曜日はなんようび。複合語・文脈を優先。 |
| 練習1のカタカナ | 1.1/1.2だけ、STTのカタカナをひらがなにして表示。これは他の練習へ広げない。 |
| 練習2以降のカタカナ | 2.1/2.2/2.3/7.1/7.2/7.3/8.1はカタカナのまま表示。STTが返した教材カタカナ語は結果でもカタカナを保つ。ただし元からひらがななら保持規則が優先し、Tシャツ/Form等の明示例外だけ変換する。作文1/発音2は末尾番号を文法練習1の意味に解釈せず、現行のカタカナ保持を継続する。 |
| Tシャツ | 表記はTシャツ固定。ただし1.1/1.2のHiragana OnlyではTしゃつ。Hiragana Onlyでも英字Tを許容する。明示キューがある場合のてぃーしゃつ/Tしゃつ/ティーシャツも統一対象。キューがないてぃーしゃつは保持する。 |
| Form | STTがFormならFormのまま、ふぉーむならForm。ひらがな保持に対する明示例外。語の途中のform等まで置換しない。 |
| 専攻 | **practice1.2だけの特別対応。** 専攻の課題で先行/選考/線香/閃光/潜行/千校/千項/せんこう等をHiragana Onlyではせんこう、With漢字では専攻へ統一。登録語句として照合し、先行研究などの部分文字列へ適用しない。共通辞書へ無条件登録せず、1.1・2以降・作文・発音へ影響させない。 |
| 文末わ | 現時点で一律わ→は変換は不要。将来、課題の文型と位置から助詞はと確定でき、必要性を確認した場合の限定対応は許す。語尾だけから推測しない。 |
| 句読点 | STTが返した句読点を表示する。表示用に削除したり、全角？を半角?へ変える全体NFKCを適用しない。TTSのポーズ用読点とは別。 |
| 空白 | 表示では原則保持し、判定では無視。英語語句の語間を全削除しない。連続空白/改行は画面内で折り返す。空白のみの結果は有効発話にしない。キューに未指定空白を足さない規則とは別。 |
| 漢字モード | STTがかなで返した語は、現在課題のキューに登録された表記と文脈が確定できる範囲でキューの漢字へそろえる。読みに対応する一般的な漢字を推測しない。未習漢字を追加しない。専攻の表記統一は上記の1.2限定例外。 |

## 承認済みの変換原則

1. 表示変換は現在課題の登録語と文脈に限定する。
2. 複合語全体を優先する。本/人/今などを別語の途中で機械的に置換しない。
3. 表示と判定の変換関数を分離する。判定で吸収する同音表記/語尾/数字等を結果欄へ自動反映しない。
4. モデルや正答へ発話全体を置き換えない。未登録語の読みを捏造しない。

## 改修前の実装との差分（以下は旧実装の監査記録）

- 1.1/1.2/2.1/2.2/2.3/7.1/7.2/7.3では、STTカタカナが原則ひらがな化される。2以降は新仕様へ変更が必要。
- TシャツはTしゃつ/てぃーしゃつ/Tシャツが混在。Formの既存ひらがな例外は主に7.1/7.2だけ。
- 1.2のWith漢字は現状先行等を原文のまま表示し、専攻統一が未実装。
- 1.1/1.2/作文1/発音2等に句読点や空白を削る処理がある。複数ページの全体NFKCは？や全角空白も変える。
- 1.2/作文1に文末わ→はが残る。
- 看護婦→かんごし、日本人→日ほん人/にほんひと、今日→いま日などは新原則に反する誤変換。看護婦の読みはかんごふであり看護師へ勝手に直さない。同義語の判定許容は別問題。
- 前回の原文/表示監査と今回のカタカナ等の実行監査資料は作業環境に保存。上記はその照合結果で、アプリ資産として監査スクリプトや一時ファイルを同梱するものではない。

## 境界例の確定方針

| 例 | 注意点・扱い |
| --- | --- |
| すまほ/こーひー | 明示キューがなければHiragana Onlyではかなを保持、漢字モードでは教材登録のスマホ/コーヒーへそろえる。 |
| てぃーしゃつ/Tしゃつ/ティーシャツ | 明示キューがあればTシャツへ統一。1.1/1.2のHiragana OnlyではTしゃつ。キューがなければSTTのてぃーしゃつは保持。 |
| フォーム/form/FORM | 指定されたForm/ふぉーむと区別。これらをFormへ強制する対象には加えない。informal等の語中のformを変更しない。 |
| ｶﾊﾞﾝ/カバン、半角/全角英字 | 同じ語でもコード表記が異なる。判定用の正規化は可能。表示全体のNFKCで句読点や空白まで変えない。 |
| かみ/はし/きる | 紙/髪/神、橋/箸、着る/切るを読みだけで決めない。現在課題の登録語と文脈を確認し、別語の中へ適用しない。 |
| 何人/一日/生 | なんにん/なにじん、ついたち/いちにち、せい/なま等。何・人・日など単一漢字の一律置換にしない。新問題を追加するときに読みを登録する。 |
| 3,000円/六時/6:00 | 数字をかなへ直すか残すかは別の表示方針。桁区切りカンマを句読点と同じ規則で消さず、数値の意味を保持する。今回一律変更を追加しない。 |
| メアリー/ロバート/たけし | 固有名の表記は課題の登録名に従う。別の人名へ一般的に置換しない。With漢字でも未習漢字を当てない。 |
| 私の/あなたの、ここ/そこ | 表示モード変換を理由に、所有者・人称・指示語をモデルの正答へ修正しない。誤答は元の内容が分かる表示を維持する。 |

## 実装の境界と保全

- `register` に教材の表記・読みを登録し、複合語全体と現在キューを優先する。同じ読みの候補が複数なら漢字を推測しない。未登録・曖昧な漢字は原表記を残し、新課題で文脈に合う読みを登録する。数字＋人など未登録の助数詞も推測しない。
- Form/ふぉーむは独立語として照合。informalやぷらっとふぉーむの部分置換は禁止。半角・全角、桁区切り、記号は表示全体の正規化対象にしない。練習1の半角カタカナ部分だけは、かな化のため局所的に処理する。
- 誤答の比較では既存の判定用正規化を維持するが、赤字・不足マークの表示位置は元の表示文字に対応付ける。全角文字や句読点を誤答時だけ変えてはならない。
- 結果欄はpre-wrapで認識結果の空白・改行を保持し、画面幅内で折り返す。原文保存時にtrimしない。空白のみの発話の無効判定は継続する。
- 発音・認識品質は実機確認事項。自動テストは表示規則・原文保持・既存判定と録音経路を検証する。
