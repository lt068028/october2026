- 本書は、2026-11-14にユーザーが確定したF3 / W9 / C2の一覧を基準に情報を追加したもの。
- 過去の未照合情報を遡って全面照合する作業は行わない。
- 正式ステータスは「未着手／進行中／確認待ち／保留／完了」の5種類。今回の確定一覧では個別項目の正式ステータスを完全に確定していないため、追加情報だけを根拠に正式ステータスを新規設定しない。

- 分類・優先順位・正式ステータスの変更、および卒業にはユーザーの明示的承認が必要。
- 「完了」と「卒業」は別。卒業は必要な確認を終えた後、ユーザーが明示的に承認した場合に限る。
- 不明点が作業の正確性に影響する場合は推測せず、必要な調査を独立レビュー担当へ依頼する指示書を作成する。
