# 練習2：指示語のタスク仕様

更新：2026-10-26。現在の実装対象は2.1のみ。2.2（この／その／あの／どの）と2.3（ここ／そこ／あそこ／どこ）は今後、2.1の実機評価を踏まえて設計する。

## 共通の場面と操作

- AとBが離れて向かい合う。O1はA側、O2はB側、O3は二人から遠い無人の場所。番号は各図で共通。「それ＝中距離」や「第三者の所有物＝あれ」とは定義しない。
- 各図では同種類のアイテムを3つ置く。色とObject番号で視覚的に識別する。色名は出題・返答・判定条件に使用しない。アイテムによって色と位置の対応を変え、色を正答に結び付けない。
- 図はページ内SVG。外部画像やチャットの添付表示には依存しない。キュー行のホバー／キーボードフォーカスで、その図の話者と対象Objectを強調する。
- キューは `[Speaker] A／[Object] 1` 等。Question／Responseの役割、Exampleのモデル文、きく／とる／停止と結果欄は1.2を踏襲。
- VocabはHover／Display／OFF、ScriptはHiragana Only／With漢字、Speech StyleはFormal／Informal／Casual。130%の表示、語彙Hover20px／操作説明18px、画面内位置補正、通常操作の自明な説明撤去を継承。
- Casualでも、このページでは主題の「は」をモデルに残す。Formal肯定「です」／Informal「だ」／Casual「だよ」。名前を聞く質問はFormal「なんですか」、Informal／Casual「なに？」。以下の文例はFormal。
- 録音・音声認識・判定・録音後リレー、再録音による旧再生中断、Autostop／Manual、AutoPlay、Voice選択を1.2から踏襲。設定変更で録音と保存済み判定、出題内容を消さない。Text／HideやY/N選択は設けない。

## Example 1・Drill 1：肯定文

Example 1は3冊の本と、Aが話す3文。

| キュー | モデル |
| --- | --- |
| A／O1 | これは、ほんです。 |
| A／O2 | それは、ほんです。 |
| A／O3 | あれは、ほんです。 |

D1はかばん・かさの2セット。各セットにO1～O3の図と、A視点の肯定文3つを置く。合計6発話。最初の提案の「A・B各1文×3問」ではなく、この構成を採用。

## Example 2・Drill 2：名前を尋ねる会話

Example 2は3本のペン。Aが質問し、Bが返答する3組、合計6文。

| 対象 | Aの質問 | Bの返答 |
| --- | --- | --- |
| O1 | これは、なんですか。 | それは、ペンです。 |
| O2 | それは、なんですか。 | これは、ペンです。 |
| O3 | あれは、なんですか。 | あれは、ペンです。 |

D2はとけい・さいふの2セット。各セットでO1～O3について同じ質問・返答を練習する。合計6会話・12発話。Y/N質問ではない。選択を先に行う前提条件はなく、モデルを聞かずに録音できる。

## Example 3・Drill 3：どれ

Example 3は3冊の本。Bが「あなたのほんは、どれですか」と質問し、Aが指定Objectについて返答する。

| Aの対象 | Aの返答 |
| --- | --- |
| O1 | これです。 |
| O2 | それです。 |
| O3 | あれです。 |

3つの返答は指定Objectを変えた別のケース。図の近くにあることと所有者は区別し、キューのObjectがAの所有物であるという課題条件で出題する。

D3は6問。それぞれBの質問とAの返答を録音できる。ほん・ペン・かばん・さいふ・かさ・とけいを1回ずつ使い、各問は同じ種類の3つのアイテムの図を持つ。初回ページ読込でアイテム順と対象Objectをシャッフルし、O1／O2／O3が各2問になるようにする。文体・表記・Vocab変更や再録音では再抽選しない。ページ再読込時は新しい並びになる。
