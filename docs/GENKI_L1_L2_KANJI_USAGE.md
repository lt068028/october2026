# Genki L1・L2 参考語彙と使用ページ

更新：2026-10-28。対象：練習1.1・1.2・2.1・2.2・2.3の全セット。語の右に使用ページを記載。

## 見方

- 例：学生（1.1、1.2）、本（2.1）。ページ内の繰り返し回数は表示しない。
- 手本文とは、こちらが用意した読み上げ・例文用の文のこと。手本文や問題、選択肢に登録した語を、そのページで使用している語とする。学習者の発話履歴ではない。
- 自由入力の全組み合わせは含めない。同じ語はページごとに1つの使用箇所として示す。
- 未使用も明記する。既習漢字一覧ではなく、語彙欄の参考漢字を確認するための表。公開リストを照合した確認用で、版差を含み、出版社紙面の完全な転記ではない。
- この表は参考漢字のある語が中心。Genki全語彙の網羅表ではないので、この表だけから語彙カバー率を計算しない。

## 照合元と再集計

- [出版社公式・文字表記と学習進度](https://genki3.japantimes.co.jp/en/intro/index.html)
- [L1語彙表](https://steven-kraft.com/projects/japanese/genki/vocab1/)／[L1の補足語彙](https://ohelo.org/japn/lang/genki_vocab_table.php?lesson=1)
- [L2語彙表](https://nihongo-net.com/2019/07/24/genki1-lesson2-vocabulary/)／[L2照合](https://www.kakimashou.com/curricula/genki/lesson-2)
- [L1補足の第3版照合](https://quizlet.com/1205514662/genki-additional-vocab-from-lesson-1-japn-1010-flash-cards/)では看護師・工学・生物学・家族等も確認。専攻／専門、カタカナ表記等の版差がある。現行コードのせんこうは専攻として数え、専門に統合しない。L1・L2の両方に出る語は各表に同じ使用ページを再掲する。
- `node scripts/genki-kanji-usage.cjs`で再生成。出題パターンの変更時はこの監査スクリプトの枠定義も更新する。全枠の語を記録した[集計データ](GENKI_L1_L2_USAGE_UNITS.json)で検算可能。
