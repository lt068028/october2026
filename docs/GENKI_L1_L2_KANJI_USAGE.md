# Genki L1・L2 参考漢字の語彙と使用回数

集計日：2026-10-27。対象：練習1.1・1.2・2.1（全セット）。教材の漢字学習リストではなく、語彙欄の参考表記を確認するための一覧。版による語彙の入れ替えを含む公開リストを照合した確認用で、出版社紙面の完全な転記ではない。

## 回数の意味

- 語の右の（N）は、**固定モデル／固定部分の出題枠＋選択肢の登録枠**の合計。かな表示でも同じ語として数える。語を含むモデル文は1文につき1回。
- Exampleと全セット、Yes／Noの別モデルも対象。D1 S2の許容する長い返答は追加計上せず、標準の短いモデルのみ数える。
- 1.1 D2の選択肢と1.2 D2の専攻選択肢は、同じ候補を複数行で繰り返し表示しても、ページ内の登録1枠として別計上。全組み合わせへ展開しない。自由入力・実際の選択／発話履歴は対象外。
- 1.2 D2の返答テンプレートでは、固定の人物語・専攻だけを数え、専攻の候補語は選択肢欄へ分離。
- 見出し・キュー・モデル表示・画像ヒント・認識結果を重複加算しない。例：同じ本をAとBが1文ずつ述べるEx1は本（2）。
- 日本人の中の日本、留学生の中の学生は別語として重複加算しない。接尾語の語／歳／時／年生だけは語末の使用を数える。人は語尾をじんと読む国籍等の語だけを数え、恋人のびとは含めない。
- 0も記載する。鞄は参考表記として掲載するが、このサイトのWith漢字ではカバンを使用する。

## 上記リストにない使用済み漢字語

L1・L2の参考表記に自動で追加してよいとは限らない語。現在の独自練習・選択肢にあるため、Genki進度へ揃える際の確認対象とする。

アメリカ人（1）、上司（1）、兄弟（1）、公務員（1）、同僚（3）、外国人（1）、子供（1）、孫（1）、店員（1）、恋人（1）、研究者（1）、自営業（4）、親友（3）。
