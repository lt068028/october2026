- `node tests/tts-model-script.cjs`で各ページの代表モデルを実際の再生ボタンから取得し、22項目を検証。ブラウザ標準TTSはモックし、発音の良否は判定しない。
- 生成元のコードも照合。既存1.1・1.2・7・作文・発音はkanji系データまたは読み上げ用漢字変換を利用。練習2の3ページにはその処理が欠け、表示モードに連動していた。
- 練習2では既知語彙と金額の読みを漢字かな交じりへ変換し、千円・二千円・三百円などをTTSへ渡す。表示・認識比較・判定は変更しない。固有名のたけしは読みが曖昧な武へ変換しない。
- 1.1 D3の自由入力は従来どおり入力文字列を用いる。カタカナ語・固有名・助詞などを無理に漢字にする仕様ではない。7.3のよるくじ等、確定済みの読み指定も維持。
- 練習2の各モデル・文体・表示モードはpractice21.cjs／practice2-next.cjsで別途検証。代表1件だけで全発話の音響品質を保証しない。
