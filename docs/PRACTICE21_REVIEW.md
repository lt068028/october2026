# 練習2.1 改訂後の点検（2026-10-27）

現行実装を点検した記録。下記の追加案・回答許容変更は、この点検だけでは実装しない。

## 優先して方針を決める点

1. **D1 Set 2の短い返答と長い返答の許容差**
   - 標準は「いいえ、それはノートです。」。
   - 「いいえ、辞書じゃないです。ノートです。」は許容済み。一方「いいえ、ノートです。」は現在の許容文に含まれない。
   - 指示語を使わせることを優先するか、自然な省略も認めるかで、短答と長答の扱いを揃える必要がある。現行判定は変更しない。
2. **D3の返答形式を説明文で明確にする**
   - 現在は「色で示した対象に答える」と案内。判定はこれです／それです／あれですを求め、色名を答える文や品名だけの文は対象外。
   - 学習者が回答の形式を推測しなくてよいよう、「Use これ／それ／あれ.」程度の短い指示を足す案。未実装。

## 今後の改善候補

- **色と場所の固定を崩す**：D3はredがA側、blueがB側、greenが棚で固定。質問役は交代するため視点の練習はできるが、慣れると色と位置の対応を覚えて答えられる。次段階では品物セットごとに配色位置を変える等を検討。自動ランダム化・録音結果の扱いは別途設計する。
- **未使用語を次ページへ分散する**：傘・鉛筆・靴・自転車、食べ物・場所語などは現在の参考表で未使用。2.1へ問題を増やすより、2.2で未使用の物・食べ物、2.3で銀行・図書館・郵便局等の場所を優先する方が学習目標を保ちやすい。
- **語彙表の母集団を確定する**：現在の一覧は参考漢字のある語を中心にした照合表で、版差も含む。Genki全語彙のカバー率を数値で出すには、使用する版・基本語彙／補足語彙・かなだけの語も含む対象一覧を先に確定する。

## 整理事項・既知の制約

- 使用情報は回数ではなく「学生（1.1、1.2）」のようにページで管理する。手本文とは、こちらが用意した例文・読み上げ文を指す。選択肢に登録しただけの語も使用ページには含まれるため、実際の発話履歴とは区別する。
- 辞書表紙などの漢字は画像の一部で、Script Modeでは切り替わらない。L2の参考漢字方針と合わせて、文字表示の切り替え対象を明記済み。
- 古いSVG図示・旧出題の補助関数やデータが残る。現行の写真・Drill 1～3と未使用処理を、次の保守で棚卸しする余地がある。録音制御を巻き込む大規模整理は今回行わない。
- TTSのCasual疑問文の語尾、声質、音声認識の実音精度はブラウザ／端末依存。自動検証は出力する文・操作の競合・判定等であり、実音の質まで保証しない。
- 自動表示検証はPC幅600px以上。スマホの録音・認識対応や、Braveへの注意表示の追加判断は既存の保留事項。
