## 1. 共通：Voice・表示・状態保持

- [ ] 未保存状態のChrome（例：シークレットウィンドウ）で各練習ページを開く。利用可能な「日本語3」が選択され、その音声でモデルが再生される。
- [ ] Voiceを手動変更し、ページ移動・再読込後も選択が残る。保存済み設定を新しい初期Voiceで強制上書きしない。
- [ ] 明色／暗色と、通常幅／狭いPCウィンドウで、ヘッダー・設定・キュー・ボタン・Voice欄が整理前と同じように表示される。
- [ ] 録音後にScript Mode・Speech Style・Vocabを切り替えても、そのページの確定した範囲で音声・元の結果・判定が保持される。発音1には文体／Vocab／テキスト判定を要求しない。

- [ ] モデル音の速さを試聴する。Practice 1.1・1.2は0.75、Practice 7.1〜7.3は暫定0.8。Example・個別再生・録音後リレーで同じ指定を使う。自分の録音は等速のまま。

## 3. CSS整理後の代表操作

全ページの見た目を確認し、以下の共通操作は代表ページでも確認する。特定ページで異常があればそのページを追加確認する。

- [ ] 録音・許可待ち中の設定／Voiceは操作不可とわかる。Manualの当該停止は有効。終了後は操作できる。
- [ ] 通常行の自動リレーは両ボタンが全区間Playing、手動個別再生は当該ボタンのみPlaying。Labの自分のみ再生も当該ボタンのみ。
- [ ] 再生中のAutoplay変更は可能。開始済みリレーは最後まで続き、変更は次回の録音後から適用する。
- [ ] 別行の録音・別再生を開始すると旧再生が止まり、古い通知で復活しない。
- [ ] Voiceメニュー、ツールチップ、Yes／No選択、キュー切替、Lab課題選択が表示され、禁止状態と選択状態が見分けられる。
